Nhìn theo luồng này là dùng được
Thiết lập nhà trọ một lần, thêm phòng và người thuê, rồi mỗi tháng chỉ cần tạo phiếu thu, thu tiền, theo dõi công nợ và xuất báo cáo.
Luồng làm việc chính
1. Cài đặt
Tên nhà trọ, chủ trọ, logo, font, Firebase.
2. Tạo phòng
Khu, tầng, giá thuê, điện nước, 2 ảnh phòng.
3. Thêm khách
Hồ sơ, CCCD, người ở cùng, gán phòng.
4. Hợp đồng
Tạo hợp đồng, theo dõi sắp hết hạn, in CT01.
5. Thu tiền
Nhập chỉ số mới, tạo hóa đơn, ghi thanh toán.
6. Công nợ
Xem ai còn nợ, bấm Thu nợ để xử lý ngay.
7. Báo cáo
Xem tháng/quý/năm, xuất Excel khi cần.
8. Đồng bộ
Kết nối Firebase để dùng chung nhiều thiết bị.

📋 Tạo Firebase Realtime Database miễn phí:

1. Vào console.firebase.google.com

2. Click "Add project" → đặt tên → tạo project

3. Vào Build → Realtime Database → Create database

4. Chọn "Start in test mode" (cho phép đọc/ghi tự do)

5. Vào Project Settings (⚙️) → General → Add app → Web (</>)

6. Copy toàn bộ firebaseConfig rồi dán từng trường vào tab Cấu hình

💡 Miễn phí mãi mãi: 1GB lưu trữ · 10GB/tháng bandwidth · Đủ dùng cho vài chục phòng trọ
⚠️ Bảo mật: Sau khi test, vào Database → Rules để giới hạn quyền truy cập. Không chia sẻ file HTML có API key ra công cộng.
